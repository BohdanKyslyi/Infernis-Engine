# Infernis Engine PBR-матеріали

Infernis Engine забезпечує підтримку PBR для відтворення metallic/roughness карт текстур, у рендерері R4/DX11, при цьому не змінюючи старі матеріали X-Ray.

## Увімкнення PBR

Відкрийте метадані базової текстури у форматі `.thm` і виберіть тип матеріалу `Infernis Engine -> PBR`. Текстура повинна використовувати карту рельєфу. Після цього рендерer компілює спеціальний варіант шейдера `USE_PBR` і позначає матеріал у G-буфері, завдяки чому сонце, локальні джерела світла, освітлення навколишнього середовища та прохід комбінування використовують PBR-шлях.

Після зміни вихідного коду шейдера або режиму калібрування перед запуском гри видаліть `shaders_cache`.

## Набір текстур

Для базової текстури з назвою `material.dds` набір PBR виглядає так:

| Texture | Channel | Data |
| --- | --- | --- |
| `material.dds` | RGB | Albedo/base color |
| `material_bump.dds` | R | Height карта параллаксу |
| `material_bump.dds` | G | Не враховується при реконструкції за методом PBR |
| `material_bump.dds` | A | Normal X |
| `material_bump.dds` | B | Normal Y |
| `material_bump#.dds` | R | Metallic |
| `material_bump#.dds` | G | Roughness |
| `material_bump#.dds` | B | Зарезервовано для використання в майбутньому; Не враховується при реконструкції за методом PBR на даний момент |
| `material_bump#.dds` | A | Ambient occlusion |

Залишковий Normal Z створюється самим шейдером. Albedo — це колірні дані; Normal, Height, Metallic, Roughness та AO — це текстури даних, і під час упаковки вони не повинні піддаватися додатковій художній гамма-корекції.

## Як працюють значення PBR-матеріалів?

- Metallic: `0` для діелектриків і `1` для провідників. Уникайте довільних відтінків сірого, якщо тільки поверхня не поєднує два типи матеріалів навмисно.
- Roughness: `0` — дзеркально гладка поверхня, а `1` — повністю шорстка. Рендерер застосовує невелике мінімальне та геометричне згладжування дзеркальних відблисків для стабільності.
- AO: `1` — без затінення, а `0` — повне затінення. AO впливає на непряме освітлення; це не заміна тіней від прямого світла.
- Metal base color відображає кольорове відбиття при нормальному падінні світла (F0). Дуже темний металічний Albedo створює фізично темний метал, оскільки метали не мають Diffuse-запасного варіанту.

## Стандартний шлях освітлення

- Розподіл GGX/Trowbridge-Reitz з видимістю Smith та Schlick Fresnel.
- Окремі калібровані шкали енергії Сонця, місцевого освітлення та навколишнього середовища.
- Спеціальні кубічні карти середовища `env_s0`/`env_s1` для дзеркального IBL.
- Міпи кубічних карт, підібрані за Roughness, у межах перевіреного діапазону LOD.
- Компенсація енергії багаторазового розсіювання для шорстких поверхонь GGX.
- Старі матеріали продовжують використовувати оригінальний шлях освітлення X-Ray.

## Аудит локального металу

Результатом роботи `orm` є `R=metallic`, `G=roughness` та `B=hemi*AO`. Режими Albedo та Normal відображають значення, що збереглися після відкладеного G-buffer. Локальний косинусний зонд перевіряє положення, напрямок світла та `NdotL` без використання GGX; режим дзеркального відбиття зберігає лише GGX/Fresnel lobe для локального світла. Завжди видаляйте `shaders_cache` після завершення перевірки.
