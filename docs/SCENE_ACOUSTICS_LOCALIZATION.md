# Акустика сцени та локалізація

У меню звуку є три незалежні налаштування: «Акустика сцени», «Мова тексту» й «Мова озвучення». Акустика працює за наявності EFX. Типова настройка `snd_acoustics` — `0`; її можна змінити через меню або консоль (`snd_acoustics 1`).

Система збирає приблизні перешкоди з активних об'єктів сцени на ігровому потоці, а також оцінює закритість приміщення по геометрії рівня. Вона не потребує особливих файлів для кожної мови. Перемикання мови озвучення використовує `gamedata/sounds/localization/<код>/...`, підбираючи для кожного звуку файл вибраної мови або базовий файл. Поради щодо додавання мов наведено в `docs/LOCALIZATION.md`.

Змінені файли пакета можна накласти на відповідну версію `main` форку. Збирати разом `xrEngine`, `xrSound` та `xrGame`: звук і рушій отримали спільні зміни інтерфейсу.
