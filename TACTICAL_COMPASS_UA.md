# Тактичний компас Infernis Engine

Нативна горизонтальна шкала напрямків у HUD одиночної гри. Вона орієнтується за напрямком камери; біля шкали відображаються маркери точок карти. Для цілі в центрі показується назва над шкалою та дистанція під нею. Компас працює без Lua-скриптів чи MCM аддону для Anomaly.

## Налаштування

У `gamedata/configs/infernis_engine/engine_external.ltx`:

```ini
[ui_extensions]
enable_tactical_compass = true
```

Відсутній ключ вважається увімкненим для сумісності зі старими конфігами. Розміщення, розмір і дистанція маркерів задаються в `gamedata/configs/ui/ui_tactical_compass.xml`:

```xml
<tactical_compass x="332" y="40" width="360" height="66"
                  show_markers="1" marker_max_distance="500"
                  enemy_max_distance="120" marker_y="-2"
                  focus_angle="20" distance_unit="m">
```

Маркери можна вимкнути окремо (`show_markers="0"`). `marker_y` зміщує іконки відносно шкали; `focus_angle` задає кут у градусах, за якого показуються назва й дистанція. `distance_unit` дозволяє замінити `m` на локалізоване скорочення. Показуються до 16 найближчих точок; обране гравцем завдання має пріоритет і не обмежується дистанцією. Інші точки залежать від `max_distance` свого стилю. Список перевіряється раз на 200 мс, а позиції й шкала оновлюються разом із камерою. Для офлайн-цілей відображається лише позиція на поточному рівні, якщо вона доступна в `CMapLocation`.

## Іконки для точок карти

Координати іконок задаються в `gamedata/configs/ui/ui_tactical_compass_spots.xml`. Ім'я `type` збігається з назвою секції `level_spot` в `map_spots.xml`. **Точки без правила не показуються**; `*` не підтримується. Для нового аддону достатньо додати відповідне правило, не перекомпілюючи рушій:

```xml
<spot type="my_new_level_spot" texture="ui\my_icons"
      x="60" y="30" width="30" height="30" size="18"
      offset_y="0" max_distance="500" />
```

`texture` - шлях до DDS без розширення в `gamedata/textures` (або аддоні), а `x/y/width/height` - координати прямокутника в атласі. `size` задає висоту іконки в HUD; ширина підбирається за пропорціями прямокутника і співвідношенням сторін екрана. `offset_y` і `max_distance` необов'язкові. Наприклад, `max_distance="300"` для квестів і `max_distance="50"` для `friend_location` / `neutral_location`; за відсутності параметра діє `marker_max_distance` або `enemy_max_distance` з основного XML. Спеціальні правила `@quest_storyline`, `@quest_additional` використовують реальний тип завдання (`GetTaskType()`), незалежно від назви помітки; обраний квест відображається навіть за межами `max_distance`, якщо його точка є на поточному рівні та потрапляє в кут огляду компаса. `@enemy` застосовується до живих ворожих NPC, яких бачить актор або виявляє шолом у своєму радіусі. Для інших точок замість назви квесту використовується доступна підказка карти. Якщо спеціальне правило не задано, квест або ворог показується тільки за явного правила для його базового `level_spot`.

Текстури шкали, рамки й маркерів взято з наданого архіву Tactical Compass 1.1 (автори, зазначені в його скриптах: Strogglet15, Tronex, RavenAscendant, explorerbee; попередній дизайн A.N.T.H.O.L.O.G.Y.). Це окремий HUD-компонент: MCM-налаштування та всі категорії маркерів аддону Anomaly сюди не перенесені.
