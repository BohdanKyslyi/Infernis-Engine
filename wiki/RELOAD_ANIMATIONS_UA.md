# Анімації перезаряджання зброї

Для магазинної зброї з патроном у патроннику задавайте в секції зброї:

```ini
ammo_mag_size = 40
chamber_round = true
```

Це 40 патронів у магазині та один у патроннику: перезаряджання з нуля
заряджає 40, а наступне натискання перезаряджання додає ще один патрон,
до 41. Перезаряджання непорожньої зброї також може довести її до 41.
Без `chamber_round` зберігається звична поведінка: `ammo_mag_size`
позначає повну місткість і повторне заряджання після досягнення цієї межі
не запускається. Тому для нового режиму вказуйте місткість саме магазину,
а не суму «магазин + патронник».

У секції HUD:

```ini
anm_reload         = hands_reload, weapon_reload
anm_reload_full    = hands_reload_empty, weapon_reload_empty
; Синонім: anm_reload_empty
anm_unjam          = hands_clear_jam, weapon_clear_jam
; Синоніми: anm_reload_misfire, anm_reload_jammed
```

У секції зброї відповідні звуки: `snd_reload`, `snd_reload_full` або
`snd_reload_empty`, `snd_unjam`, `snd_reload_misfire` або
`snd_reload_jammed`. Спеціальні ключі необов'язкові: повна
перезарядка і усунення осічки повертаються до `anm_reload` і
`snd_reload`, якщо спеціальних ключів немає. Для зброї з підствольником
підтримуються `*_w_gl` варіанти анімацій із поверненням до базових.

Для дробовиків з `tri_state_reload = on` можна задати в HUD
`anm_add_cartridge_empty`. При перезаряджанні порожньої зброї спочатку
виконується ця анімація, після неї додається один патрон і запускається
звичайний цикл `anm_open` → `anm_add_cartridge` → `anm_close`.
Звук першого патрона `snd_add_cartridge_empty` задається в секції зброї;
без нього використовується `snd_add_cartridge`. Необов'язкові
`anm_open_empty` і `snd_open_weapon_empty` відтворюються під час
відкривання порожнього дробовика. Якщо спеціальної анімації першого
патрона немає, зберігається початковий трифазний цикл.

Необов'язкові `anm_show_empty`, `anm_hide_empty`, `anm_bore_empty`,
`anm_idle_empty`, `anm_idle_aim_empty`, `anm_idle_moving_empty` і
`anm_idle_sprint_empty` працюють і для інших класів магазинної зброї.
За відсутності варіанта для порожньої зброї використовується базовий рух.
Для пострілу підтримуються обидва найменування: `anm_shots` і `anm_shoot`.
