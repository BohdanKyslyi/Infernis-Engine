# Індивідуальний FOV для HUD-секцій

Будь-яка HUD-секція може необов'язково задати абсолютний FOV у градусах або
замінити глобальний множник `hud_fov` із `user.ltx`. Механіка однакова для
звичайної зброї, детекторів та тимчасових HUD-моделей `ItemUseController`.

## Глобальне значення

Без локального параметра рушій використовує штатне консольне значення:

```ini
hud_fov 0.45
```

`hud_fov` є множником FOV основної камери, а не значенням у градусах. Чинний
діапазон лишився штатним: від `0.1` до `1.0`.

## Абсолютний FOV у градусах

Рекомендований параметр для моделей, створених під конкретний кут проєкції:

```ini
[wpn_example_hud]
hud_fov_degrees = 95
```

Допустимий діапазон — від `5` до `179` градусів. На відміну від множника,
абсолютне значення може бути більшим за поточний FOV основної камери. Наприклад:

```text
основний FOV = 60°
HUD FOV      = 95°
множник      = 95 / 60 = 1.5833
```

Ефективний множник перераховується щокадрово. Тому zoom, camera effector або
інша тимчасова зміна `Device.fFOV` не змінює задані `95°` HUD-проєкції.

Якщо в одній HUD-секції вказані обидва параметри, пріоритет завжди має
`hud_fov_degrees`:

```ini
hud_fov         = 0.52
hud_fov_degrees = 95
```

## Зброя та звичайні HUD-предмети

Параметр треба додавати саме до HUD-секції, на яку посилається фізичний предмет:

```ini
[wpn_ak74]:weapon_probability, default_weapon_params
hud = wpn_ak74_hud

[wpn_ak74_hud]
item_visual      = dynamics\weapons\wpn_ak74\wpn_ak74_hud.ogf
attach_place_idx = 0
hud_fov_degrees  = 95
```

Послідовність роботи:

```text
Вибір предмета -> attach HUD -> застосування локального FOV
Прибирання     -> detach HUD -> повернення значення з user.ltx
```

Зміна впливає на весь HUD-проєкційний прохід: руки, предмет, HUD-партикли та
PBR-проєкційні параметри використовують одне й те саме актуальне значення.

## Анімації ItemUseController

Той самий ключ можна додати до HUD-секції консерви, цигарки, ПДА, рюкзака,
вдягання екіпірування або зрізання частин мутантів:

```ini
[mutant_looting_hud]:base_consumable_hud
item_visual      = dynamics\weapons\wpn_knife\wpn_knife_hud.ogf
attach_place_idx = 0
hud_fov_degrees  = 82
anm_show         = mutant_looting
snd_show         = interface\mutant_looting
```

Override починається лише після успішного attach тимчасового HUD і гарантовано
знімається під час штатного завершення, скасування або fallback контролера.

## Пріоритет і fallback

Оскільки всі HUD-моделі кадру використовують одну проєкцію, джерело FOV
обирається в такому порядку:

1. активний controller HUD;
2. основний HUD-предмет у `attach_place_idx = 0`;
3. додатковий HUD-предмет у `attach_place_idx = 1`;
4. глобальний `hud_fov` із `user.ltx`.

Якщо пріоритетна HUD-секція не має ані `hud_fov_degrees`, ані `hud_fov`,
використовується глобальне значення — параметр другорядного предмета не змінює
проєкцію основного.

Відсутні параметри повністю сумісні зі старими конфігами. Множник поза
діапазоном `0.1–1.0` або абсолютний FOV поза діапазоном `5–179°` ігнорується, а
в лог записується повідомлення `HUD FOV` із назвою проблемної секції. Якщо
абсолютне значення невалідне, рушій пробує сумісний `hud_fov`, а потім глобальне
значення. Глобальний множник запам'ятовується перед першим override та
відновлюється після останнього detach.
