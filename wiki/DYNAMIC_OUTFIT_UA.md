# Динамічні шоломи та рюкзаки актора

Рушій може окремо показувати шолом і рюкзак на акторі у третьому обличчі. Вкажи в секції предмета опціональний `actor_visual` - шлях до окремого OGF у `gamedata/meshes` (або в пакеті ресурсів, якщо файл доступний рушію):

```ini
[helm_my_helmet]:helmet
actor_visual = actors\wearables\helm_my_helmet.ogf

[backpack_my_pack]:backpack
actor_visual = actors\wearables\backpack_my_pack.ogf
```

Кожен слот використовує не більше одного візуалу. `visual` предмета для інвентаря та світу не змінюється. Якщо `actor_visual` відсутній, старі предмети працюють без змін. Шлях може бути без `.ogf`; неправильний або відсутній файл дає повідомлення в лог, але не замінює візуал актора.

## Вимоги до моделі

Основний варіант - OGF **лише з геометрією аксесуара**, але з тим самим скелетом і назвами кісток, що й у візуалу актора. Вага вершин шолома/рюкзака повинна посилатися на ці кістки. Рушій співставляє кістки за назвами і копіює актуальну позу актора, включно з позою тіла після смерті. Не додавай геометрію всього сталкера в аксесуар: вона дублюватиме модель ГГ. Для іншого скелета, в якому бракує хоча б однієї назви кістки, аксесуар пропускається з повідомленням у лог. При зміні костюма ГГ його базовий візуал повинен мати сумісні назви кісток.

Для **жорсткої моделі**, розташованої відносно однієї кістки, замість синхронізації скелета можна задати:

```ini
actor_visual = actors\wearables\backpack_rigid.ogf
actor_visual_bone = bip01_spine2
```

Для шолома типова кістка без цього параметра - `bip01_head`, для рюкзака - `bip01_spine2`. В OGF жорсткого аксесуара позиції вершин мають бути підготовлені відносно обраної кістки. Параметр `actor_visual_bone` також примусово вмикає жорстку прив'язку для скелетного OGF.

## Поведінка

Екіпірування читається зі слотів шолома та рюкзака. При заміні предмета попередній OGF видаляється, а новий створюється лише при зміні `actor_visual`; кістки переприв'язуються при зміні базового візуалу актора (наприклад, костюма). Перед смертю рушій зберігає показані аксесуари: коли стандартна логіка переносить речі зі слотів у рюкзак, їхні моделі лишаються на тілі до його знищення. При виході з рівня/повторному spawn ресурси звільняються.

Це підтримка накладних візуалів, не модифікація колізії або характеристик захисту. Для перевірки: надінь/зніми обидва предмети, зміни костюм і подивись на тіло після смерті.
