# Альтернативне прицілювання зброї

Альтернативне прицілювання вмикається окремою дією `wpn_zoom_alter` і працює,
доки призначена клавіша затиснута. За замовчуванням це середня кнопка миші;
призначення можна відновити або змінити консольною командою:

```ini
bind wpn_zoom_alter mouse3
```

Режим необхідно дозволити в конфігурації зброї або активного прицілу:

```ini
alter_zoom_allowed = true

alter_aim_hud_offset_pos = 0.0002,-0.0651,0.05
alter_aim_hud_offset_rot = -0.0001,0.0,0.0

alter_aim_hud_offset_pos_16x9 = 0.0001,-0.067,-0.103
alter_aim_hud_offset_rot_16x9 = -0.004,0.0,0.0

; Необов'язковий множник HUD FOV. Значення 1.0 не змінює HUD FOV.
hud_fov_alter_zoom_factor = 0.85
```

Для вбудованого або резервного прицілу ці параметри можна записати безпосередньо
до HUD-секції зброї. Для знімної оптики їх можна записати до її секції або до
секції-обгортки зі списку `scopes_sect`.

Пріоритет параметрів:

1. секція-обгортка встановленого прицілу;
2. секція самого прицілу (`scope_name`);
3. HUD-секція зброї;
4. секція зброї — для постійно встановленої оптики.

Якщо параметри `_16x9` відсутні, рушій використовує звичайні
`alter_aim_hud_offset_pos` і `alter_aim_hud_offset_rot`. Під час альтернативного
прицілювання 2D-маска, постпроцес і додатковий viewport 3D-прицілу не вмикаються.
