# Аддони Infernis Engine

Створи папку `addons` поруч із `gamedata`. У кожному аддоні розміщуй безпосередньо вміст `gamedata`, без додаткової вкладеної папки:

```text
game/
  gamedata/
    configs/system.ltx
    configs/infernis_engine/backpacks.ltx
  addons/
    my_backpacks/
      configs/infernis_engine/mod_backpacks_my_backpacks.ltx
      textures/ui/ui_icon_my_backpacks.dds
      textures/ui/ui_actor_armor_my_backpacks.dds
      particles/my_effect.pe
```

Шляхи всередині пакета повинні збігатися зі структурою встановленої `gamedata`. Рушій індексує окремі файли при запуску. Після встановлення, видалення або зміни аддону перезапусти гру. Папки пакетів завантажуються за алфавітом без урахування регістру: якщо **відносні шляхи файлів** збігаються, останній пакет замінює файл попереднього пакета або `gamedata`. Це заміна файлу, не злиття його вмісту. Архіви `.db/.xdb` з папки `addons` не монтуються.

## Доповнення LTX

Для базового `name.ltx` створи поруч (у тому самому відносному каталозі) `mod_name_<унікальна_назва_пакета>.ltx`. Наприклад, `configs/infernis_engine/mod_backpacks_my_backpacks.ltx` підключиться до `backpacks.ltx`, який `system.ltx` читає через `#include`. Базовий файл має існувати й бути реально завантаженим; `mod_*.ltx` без відповідного базового конфіга сам по собі не відкриється. Для торгівлі використовуй `mod_<назва_trade_файлу>_<пакет>.ltx` поруч із trade-конфігом. Для луту використовуй таке саме правило поруч із завантаженим `death_items_*.ltx` або `death_generic.ltx`.

У файлі `mod_*.ltx`:

- `[нова_секція]` створює секцію.
- `[існуюча_секція]` **повністю замінює** попередню секцію. Зазнач усі необхідні параметри або успадкуй їх через `[існуюча_секція]:базова_секція`.
- `![існуюча_секція]` додає/замінює лише вказані поля, залишаючи решту без змін. Також можна створити нову секцію з `![нова_секція]`.
- Звичайний дубль `[секція]` у базових файлах поза `mod_*.ltx` лишається помилкою.

Приклад часткової зміни рюкзака:

```ini
![backpack_stalker]
additional_inventory_weight = 20
icons_texture = ui\ui_icon_my_backpacks
upgr_icons_texture = ui\ui_actor_armor_my_backpacks
upgr_icon_x = 0
upgr_icon_y = 0
upgr_icon_width = 100
upgr_icon_height = 150
```

`icons_texture` задає атлас іконок інвентаря (координати `inv_grid_*`). `upgr_icons_texture` задає окремий атлас для іконки предмета в меню поліпшень та рейтингу (координати `upgr_icon_x/y/width/height` у пікселях). Для зброї це може бути власний `ui_actor_weapons_*.dds`, для броні й рюкзаків - `ui_actor_armor_*.dds`. Якщо параметра немає, залишиться штатний атлас відповідного типу. У LTX-шляху використовуй **один** зворотний слеш і не додавай `.dds` до імені.

`mod_*.ltx` читаються за алфавітом і можуть змінювати ті самі поля: значення з останнього файлу має пріоритет. Давай кожному пакету унікальні назви файлів, інакше два `mod_*.ltx` з однаковим відносним шляхом не завантажаться одночасно. Успадкування секцій обчислюється під час їх читання: пізніша заміна базової секції не перераховує вже завантажених нащадків. Це система файлів і конфігів, а не менеджер залежностей аддонів.
