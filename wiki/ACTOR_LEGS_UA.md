# Ноги актора від першої особи

Infernis Engine підтримує окрему HUD-модель ніг, яка синхронізується з анімаціями
звичайної моделі актора. Система не замінює HUD рук і не вимагає дублювати
анімації ходьби, бігу, присідання або стрибка.

## Увімкнення

У секції `[hud_extensions]` файла `engine_external.ltx`:

```ini
[hud_extensions]
enable_actor_legs = true
```

За замовчуванням параметр вимкнений, тому старі конфіги й модифікації без моделей
ніг продовжують працювати без змін.

## Модель для кожного HUD рук

Додайте `legs_visual` до секції HUD рук, яка використовується актором:

```ini
[actor_hud_01]
visual      = dynamics\weapons\wpn_hand\wpn_hand_01
legs_visual = actor\stalker_legs\novice_outfit
```

Коли броня перемикає `actor_hud_01` на іншу HUD-секцію, рушій автоматично
перезавантажує і відповідну модель ніг. Так можна призначити окремі штани та
взуття для кожного костюма:

```ini
[actor_hud_02]
visual      = dynamics\weapons\wpn_hand\wpn_hand_02
legs_visual = actor\stalker_legs\military_outfit
```

Значення `none` явно вимикає ноги тільки для конкретної HUD-секції:

```ini
legs_visual = none
```

Якщо всім костюмам достатньо однієї моделі, `legs_visual` можна вказати один раз
у `[hud_extensions]`. Значення з конкретної `actor_hud_*` має вищий пріоритет.

## Коригування позиції

За потреби модель можна посунути вперед/назад або по вертикалі:

```ini
[actor_hud_01]
legs_visual     = actor\stalker_legs\novice_outfit
legs_fwd_offset = -0.5
legs_y_offset   = 0.0
```

- `legs_fwd_offset`: додатне значення пересуває модель уперед за напрямком
  актора, від'ємне — назад.
- `legs_y_offset`: додатне значення піднімає модель, від'ємне — опускає.

Обидва параметри необов'язкові. Їх також можна задати у `[hud_extensions]` як
глобальні значення за замовчуванням, а потім перевизначати для окремих HUD-секцій.
Якщо `legs_fwd_offset` ніде не заданий, рушій використовує `-0.5`.

За замовчуванням X/Z-позиція моделі прив'язується до камери, щоб камера не
заходила всередину тіла під час анімацій, нахилів і camera effector-ів:

```ini
legs_attach_to_camera = true
```

Параметр також можна перевизначити у конкретній `actor_hud_*`-секції. Значення
`false` повертає прив'язку до звичайного `XFORM` актора.

## Вимоги до OGF

`legs_visual` повинен вказувати на скелетний `.ogf`, кістки якого мають ті самі
назви, що й кістки моделі актора. Найкращий результат дає модель, у якій геометрія
верхньої частини тіла видалена, але збережений сумісний скелет.

Дозволено вказувати й повну модель актора: контролер рекурсивно приховає шию,
голову та звичайні руки, щоб вони не накладалися на HUD-руки.

Якщо файл не знайдений, він не є скелетним або не має спільних кісток із моделлю
актора, рушій пропускає відображення ніг і пише причину в лог замість аварійного
завершення.

Ноги автоматично не малюються:

- поза камерою від першої особи;
- коли актор мертвий;
- у транспорті або іншому holder-об'єкті;
- під час руху драбиною.

Конфігурація сумісна з основним параметром `legs_visual` з IX-Ray Legs Addon.
Наявний у конфігах аддона `legs_shift_delta` можна залишити: він не впливає на
рендер моделі в Infernis Engine. Для візуального зміщення використовуйте
`legs_fwd_offset` і `legs_y_offset`.

Бінарні моделі аддона мають постачатися модифікацією окремо з дотриманням умов
їхньої ліцензії.

За основу архітектури взято підхід
[IX-Ray Legs Addon](https://github.com/ixray-community/ixray-legs-addon) до
синхронізації кісток і окремий контролер ніг із
[Monolith Engine](https://github.com/themrdemonized/xray-monolith).
